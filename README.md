# 💅 Nail Studio – Landing Page  

A glamorous and stylish **Nail Studio Landing Page** built with **Next.js, Tailwind CSS, Framer Motion, and shadcn/ui**.  
It features **smooth animations, elegant UI, and section-based navigation**, designed to highlight nail art services with charm.  

---

## ✨ Features  
- 💅 Elegant and glamorous design  
- 🎬 Smooth animations with Framer Motion  
- 📱 Fully responsive across all devices  
- 🧩 Service cards with shadcn/ui components  
- 🎨 Hover effects and interactive elements  
- 🧭 Smooth navigation-to-section effect  

---

## 🛠️ Tech Stack  
- **Next.js** – Modern React framework  
- **Tailwind CSS** – Utility-first styling  
- **Framer Motion** – Animations & transitions  
- **shadcn/ui** – Prebuilt elegant UI components
